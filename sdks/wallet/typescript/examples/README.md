# ridgeline-wallet

A basic example of how to use the ridgeline-wallet package.

## Installation

In the event `ridgeline-wallet` is not published to npm, you can install it locally by running the following command in the examples folder:

```sh
npm run setup
```

This will rebuild the parent package and install it locally.

Otherwise you can install it from npm:

```sh
npm install ridgeline-wallet
```

## Usage

To run the example, run the following command in the examples folder:

```sh
npm run start
```
